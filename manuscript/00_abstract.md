# Abstract {#sec:abstract}

Large language models are usually consumed as text generators, yet a growing class of applications needs them as *decision components*: bounded, typed answers that software can branch on. This manuscript presents {{PACKAGE_NAME}}, a composable Python toolkit for the TypeSafe Jev (System One) decision model [@typesafe2026systemone; @typesafe2026systemoneconcept]. The package reduces the entire decision surface to three typed question primitives — `noul` (a calibrated yes/no), `choice` (a labelled pick with a full probability distribution and a confidence), and `score` (a rating over ordered levels with a probability-weighted expected value) — all carried by a single HTTP endpoint. Pure-logic composition patterns (`composite_score`, `confidence_gate`, `route`/`pick`) turn typed answers into executable decisions with no additional network traffic, and a batch `Evaluator` fans a fixed question set out over many states through either the synchronous or the asynchronous client. Two live-API benchmarks quantify the practical payoff of this design.
